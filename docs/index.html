Method Overview

ChronosArt introduces an orthogonal residual decomposition pipeline built upon Visual Autoregressive (Infinity-2B) modeling, operating completely training-free in ~2.0s inference latency.

STEP 01
Scale-wise AR Prediction
Flan-T5 encodes prompt semantics, while Infinity-2B predicts coarse-to-fine residual feature maps across 10 scales ($1\times 1 \to 64\times 64$).
STEP 02
Content-Orthogonal Residual Projection
Orthogonal projector $\mathbf{P}_s^{\perp} = \mathbf{I} - \mathbf{B}_s (\mathbf{B}_s)^\top$ strips content subspace directions from style residuals, preventing leakage.
STEP 03
Safe Stochasticity
Low temperature $\tau_{\text{coarse}} = 0.15$ anchors anatomy, while $\tau_{\text{fine}} \in [0.85, 1.25]$ samples distinct micro-stroke textures per seed.
STEP 04
SAM / Rembg Segmentation
High-precision matting removes canvas backgrounds, exporting lightweight transparent WebP assets (~40KB) for instant web rendering.
