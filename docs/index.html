THEORY & ARCHITECTURE

Method Overview

Implementation of "A Training-Free Style-Personalization via SVD-Based Feature Decomposition" on Visual Autoregressive (Infinity-2B) models with safe stochasticity.

STEP 01
Scale-wise AR Prediction
Flan-T5 encodes prompt semantics, while Infinity-2B predicts next-scale residual token representations from coarse to fine ($1\times 1 \to 64\times 64$).
STEP 02
Principal Feature Blending (PFB)
Decomposes style representations via truncated SVD $\Phi_{r, \alpha}(\mathbf{F}_s) = \sum_{i=1}^r e^{-\alpha(i-1)} \sigma_i \mathbf{u}_i \mathbf{v}_i^\top$, extracting leading style directions while discarding content interference.
STEP 03
Structural Attention Correction (SAC)
Forces generation self-attention layers to synchronize Query-Key maps with the content stream ($\mathbf{Q}_s^{\text{gen}} \leftarrow \mathbf{Q}_s^{\text{con}}, \mathbf{K}_s^{\text{gen}} \leftarrow \mathbf{K}_s^{\text{con}}$) to anchor anatomical geometry.
STEP 04
Safe Stochastic Generation
Scale-scheduled temperature ($\tau_{\text{coarse}} = 0.15 \to \tau_{\text{fine}} \in [0.85, 1.25]$) and fine-scale token jittering produce distinct brushwork textures per seed without shape collapse.
